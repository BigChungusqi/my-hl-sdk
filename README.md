# 不支持内容
- 不兼容 WON 旧平台、远古 Steam 旧版半条命
- 不官方支持 Xash 引擎（可能勉强运行，无适配维护）
- 升级版 / 原版 客户端与服务器**互不互通联机**
- 禁止将升级版 DLL 直接覆盖原版游戏目录使用
- 项目定位保守，不做大型功能改版
